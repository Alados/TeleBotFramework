# TeleBotFramework

Minimalistic dependency-injection-first command framework for [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)

## Features

- ✨ Clean command structure with DI support
- ⚙️ Modular command registration
- 🚀 Ready for ASP.NET BackgroundService or webhook

## Getting Started

```bash
dotnet add package TeleBotFramework
